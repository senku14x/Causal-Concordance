Do interpretability readers report what the model actually uses?

Agreement is not truth.

Readers can agree because they share a flaw or because they all guess from the prompt. So we judge each reader against a ground truth built with no reader at all: edit the model's internal state at one token and one layer, and measure whether the answer moves.

The project in three lines

The worryAgreement can be shared errorThe J and R lenses share an estimator, the Oracle and NLA share a training lineage, and every reader can guess from the prompt. Majority vote can't be ground truth.
The ideaReadable is not the same as usedContent can be decodable at a token without the answer depending on it there. A reader that names it is not hallucinating, and not reporting what drives the answer either.
The methodCausal labels, then score the readersEach cell gets a reader-free label: used, decodable but not needed, absent, or unresolved. Then: does each reader name used content, and does it also name content that isn't needed?

How this compares to WorkspaceBench

WSB's published brew pass rates

Approximate values read off WSB's results chart. An item passes when the intermediate is named in more of 33 cells (3 answer cells × layers 20–60) than the average off-path colour.

Why the per-cell view matters

Under WSB's rule, all three token lenses pass item 0000, mostly at layers 52–60, where they name green together with black, the answer. At the last layer the model's own top choices are "black, Black, green, Green", so green there is the runner-up answer. A WSB pass can't tell a held intermediate step from a runner-up answer, and can't say whether the model uses green at that cell. Experiment 001 measures exactly that.

Glossary

cell
One token position at one layer. Labels and readouts are always per cell.
layer L
The output of block L, out of 64 (0–63).
z
The hidden intermediate the model never writes: the colour after the first stir.
margin m
log P(partner's answer) − log P(this prompt's answer), every token of every accepted spelling scored.
G
The margin difference between the two prompts of a pair: the whole effect of changing the input.
share S
How much of G one edit produces. 1 = the full flip, 0 = nothing. It can be negative.
τ, ε′
Provisional thresholds: "toward" if S ≥ 0.10, "negligible" if |S| < 0.05.
gate
The model must answer both prompts of a pair reliably, or the pair isn't used.
RHUT / SEC
Two precision setups. RHUT keeps the running residual in fp32 but multiplies in bf16. SEC runs layers 40–63 fully in fp32.
J / R / logit lens
Token readers: project a cell's vector onto the vocabulary and list the top 10 tokens.
Oracle Lens, NLA
Text readers: models fine-tuned to describe an injected activation in words.
shuffled arm
The same cell taken from a different table and given to the reader, then scored against this table's colours: the chance rate.
