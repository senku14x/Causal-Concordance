- Zhang & Nanda 2309.16042 (main text pp1–10 read in full; appendix pp11–27 not read): STR (symmetric token replacement, in-distribution, equal length) recommended over Gaussian noising (OOD; can break mechanisms, e.g. name movers' attention) (§3, §6 p8). Metrics: logit difference recommended — normalised by LD_clean − LD_corrupt (p3); probability can miss negative components (non-negativity floor, p7); LD "controls for" generic components (e.g. a head boosting all names) (p8); KL reasonable for circuit discovery. Sliding-window (multi-layer) patching inflates localization vs summed single-layer effects (≥20% more peak; nonlinear joint effects) → "experimenting with single-layer patching first" (p8-9). Which tokens are corrupted changes what is traced (p9). → Supports spec's token-aligned pairs, margin metric, and single-layer edits; RHUT's sustained 36–62 writes are the sliding-window regime (different estimand).
- Heimersheim & Nanda 2404.15255 (read in full, 13 pp): denoising (clean→corrupt) = sufficiency; noising (corrupt→clean) = necessity; "not symmetric" (§2.3). AND gate: denoising misses components; OR gate (redundant/backup): NOISING single components shows no effect (§2.4). Mean ablation "slightly more principled" than zero; corrupted-prompt patching preferred because it controls for what does not change and is less OOD (§2.5). Narrow variations for exploratory patching (§2.6). Backup/Hydra: ablation underestimates; backup compensation ~0.7× (§3.2). Metrics §4: logit/logprob difference trusted most; continuous, ~linear in logits; **false-positive: an edit that "indiscriminately damages the model" pushes toward uniform and boosts LD toward the incorrect answer** (p9) → check individual logprobs; probability nonlinear; discrete metrics (accuracy/flips) over-represent threshold crossings (p10). Summary p11.
  → Mapping to spec §6: the single-cell 1-D swap of i′'s value into x_i is a single-component edit; for redundant (OR-like) storage across positions, single-component edits show ~0 even when the representation is used as a whole (the RHUT carrier is a multi-position copy). Necessity via mean-ablation is also blind to OR redundancy (spec acknowledges). Share-vs-flips: H&N favour continuous metrics, flips as confirmatory.
- Makelov, Lange & Nanda 2311.17030 (main text pp1–27 read in full; appendices pp28–58 not read): Eq 1 p7: act_B^patched = act_B + (p_A − p_B)v — IDENTICAL in form to spec §6 swap. Illusion (p8): v = √½(v_disconnected + v_dormant): the disconnected part supplies the between-prompt variation, the dormant part supplies causal leverage; patching v "activates a dormant pathway" → behaviour changes as if the feature changed although the subspace is not what the model uses. Detection (p10): split v into causally disconnected part and remainder; patch each; check discrimination of each. **Signature (Table 1, p14-15): subspace patch effect EXCEEDS the full-component patch effect** (vMLP FLDD 46.7% vs full MLP −8%; rowspace part 13.5%). Residual stream (p17-18): no subspace in the kernel of all downstream components; v_resid patch survives removal of the "nullspace" part (140.7/127.5/123.6%); "the residual stream at the last token ... is a full bottleneck"; recommendation p27: use activation bottlenecks, "especially the residual stream", plus validations beyond end-to-end effect. FLDD ≈50% with ~0% interchange accuracy can be significant (p14) → share vs flips. DAS overfits with few items (App B.7, cited p16). 1-D patch ≈ rank-1 edit (ROME) (§6).
