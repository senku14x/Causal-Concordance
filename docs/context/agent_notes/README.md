# Agent notes (copied from the agent's persistent memory, 2026-10-03)

These are the notes Claude Code kept between sessions in `~/.claude/projects/-workspace/memory/`. On a fresh instance,
copy them back there so a new session starts with the same context:

    mkdir -p ~/.claude/projects/-workspace/memory && cp docs/context/agent_notes/*.md ~/.claude/projects/-workspace/memory/
    rm ~/.claude/projects/-workspace/memory/README.md

`MEMORY.md` is the index; each other file is one note: the PI's preferences, the commit setup and the project state.
CLAUDE.md ("Working with the PI") summarizes them. When CLAUDE.md or STATUS.md disagrees with a note, CLAUDE.md and
STATUS.md are newer.
