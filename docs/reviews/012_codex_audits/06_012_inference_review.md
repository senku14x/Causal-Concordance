# 012 design v1: inference, estimands and minimum useful comparison

Independent Codex review, 2026-10-06. Scope: scientific inference in `docs/design_specs/012_reader_concordance.md` v1 and the scientific rationale in `docs/claude_reports/32_012_outlook_2026-10-06.md`; targeted verification against experiment 007's canonical report. Repository read-only. No models, project workflows or edits were run. This report records scientific propositions rather than private correspondence.

## Assessment

A cheap Stage A replication and band comparison is worth doing: success in a band ending before L42 determines whether an on-contract NLA comparison is possible, and the four-item smoke is not sufficient evidence about it. The proposed overall experiment could become a useful study of how readers respond to causally effective interventions. As written, however, it cannot supply per-cell semantic ground truth or a general reader-validity ranking. Most serious problems are interpretations and comparison definitions, not a need for more elaborate machinery.

The best design changes before readers run are: compare all readers on the same intervention and item cohort; keep continuous reader changes and outcome changes; include prespecified failed and random controls; remove claims about the default faithful reading of hybrid states; and distinguish whole-intervention influence from mediation by the cell being read. A broad pieces-by-readers-by-arms expansion should wait for a small common-band whole-activation pilot.

## 1. A global intervention label is not a per-cell or concept-truth label

The causal manipulation acts at every prompt position over a layer band. Stage C observes one residual at WSB's `last_word_token`, downstream of that band. A changed answer therefore establishes influence of the intervention as a whole. It does not establish that the observed cell mediates the effect, or that it is where the bridge influenced computation. Other positions can carry the consequential alteration while the read cell contains only a correlated trace, untouched source information, or neither. Reading downstream avoids inspecting a coordinate immediately after writing it, but residual pathways can preserve the written component downstream without functionally using it there.

Thus the claims at spec lines 40 and 44 about labels deciding truth and being scored per cell exceed the design. The valid unit is item × arm × intervention band × rendered prompt. The captured cell is a measurement site. A positive result licenses: a reader changed in a particular way in a downstream cell following an intervention that changed the answer. It does not by itself license: the reader correctly identified what that cell demonstrably contributed to the answer.

Likewise, a targeted bridge-labelled direction can change the answer by direct answer promotion, factual association, generic disruption plus a target prior, or a role-specific bridge replacement. Random controls threaten some of these explanations, but not all. Class means help make construction independent of J-reader scores; they are not automatically semantically isolated. Full class-mean vectors also need not be geometrically outside J, so call them J-independent in construction, not a non-J lever.

The spec's failed-intervention qualification at line 227 remains too strong: no detected effect does not establish that the bridge is unused through that direction. An inadequate dose, a misaligned read/write map, redundancy, a wrong band or failure to perturb the relevant context can all produce a null. Call the outcome an unsuccessful intervention under the tested conditions. In particular, failed swaps are not true-negative examples of unused content for precision/recall of reader claims.

For the current exploratory pilot, narrowing the estimand is sufficient. If a later claim requires mediation by the observed cell, consider transferring that cell from an edited trajectory to a clean trajectory, and the complementary clean-state rescue in an edited trajectory. Positive transfer/rescue would add evidence about that cell; nulls would remain limited by distributed representation and compensation. If a claim instead requires bridge-role specificity, repeat a bridge manipulation across different downstream relations with different predicted answers: relation-appropriate changes are more informative than promotion of one fixed answer. Neither additional experiment is required merely to describe reader response to an intervention.

## 2. Stage C's interpretive rules are not justified

The claim that 84–94% of source content lies outside J converts a fraction of vector norm or reconstruction variance into a fraction of semantic content. That conversion is invalid. A small component can encode all decodable information about a particular fact, a large remainder can duplicate it, and a reader can respond nonlinearly to either. Furthermore, a two-row coordinate swap, a k=25 sparse fit and a dense rank-1024 projection are distinct objects. Numerical fractions from the Workspace examples are not measurements of these multihop interventions.

Consequently, source naming after a successful swap is not the expected behavior of a faithful reader. It has several live explanations: the source remains available; the reader summarizes retained prompt information; it misses the changed signal; or the intervention changed answer production without replacing the bridge representation. Target naming can likewise reflect a changed component without identifying which component caused the changed answer. Both source and target can coexist in a hybrid state. Naming both need not be an error.

The rule that target naming equally after failed swaps means reading the edit rather than model state is also too strong. The edit is part of the model state. Genuine representation change can fail to produce the designated answer because later retrieval or decision steps block it. Conversely, a reader can fail to name the target despite answer-changing information existing elsewhere. The observation would show that this reader response does not discriminate successful from unsuccessful interventions in this sample; that is already useful and is the strongest generally valid conclusion.

Real-target prompts are good positive controls for reader sensitivity, provided the reader can distinguish source and target there. They do not provide an exact ground truth for a hybrid edited state: a natural target prompt also changes other semantic, lexical and syntactic features. Stronger validity follows if both the model and reader respond appropriately to a range of independently specified target relations, not merely because the edited reader score moves toward a natural-target score.

A clean primary score is the within-item change in target-over-source log likelihood, with naming categories source / target / both / neither reported separately and role-sensitive hand inspection. Compare that change with the real-target versus real-source change to establish sensitivity. Avoid a per-item normalized ratio when the reference contrast is near zero. Equal render, token-position definition, answer scoring and reader batch layout matter for these contrasts.

## 3. The Oracle-versus-NLA prediction has weak and mismatched prior support

The draft predicts more Oracle swap-following because 007 found Oracle dependence on J but not NLA dependence. That was the brew `:` result. It does not transfer cleanly to multihop. The 007 canonical report gives multihop Oracle whole/J bridge D of 14.7/12.8 at L40 and 14.8/13.5 at L44; the post hoc NLA gives 14.7/14.5 at L42. Both preserve substantial bridge tracking under the dense J projection. NLA J-piece bridge naming is reported as 0.89. Restatement and reader-input-distribution caveats remain, but these data do not supply a simple multihop Oracle-dependent/NLA-independent contrast.

Also, dependence on a dense rank-1024 projection does not directly predict following a two-row J swap. The writer's support, overlap with the reader-sensitive dimensions, downstream propagation and prompt distribution all matter. Oracle > NLA is a permissible preregistered exploratory hypothesis; its rationale should acknowledge that the existing empirical prior is weakly transferable.

The draft additionally assigns Oracle L40/L44 to a band ending L35 and NLA L42 to a band ending L39. Comparing these outcomes directly would confound reader identity with four additional edited layers. The same item, arm, band and intervention trajectory must feed both readers. Prefer a common earlier band if effective; collect Oracle at its contract layers and NLA at L42 from the same run. If only a later band works, the valid experiment is Oracle-only, not an inferred negative result about NLA. Any statement about comparing two different layers must retain that scope.

Even on a common band, selecting J-swap successes and scoring J readers preferentially samples geometry aligned with their own construction. Reader-free code boundaries do not remove this dependence. Include a J-independent-construction intervention for any broader reader ranking, retain its unsuccessful attempts, and avoid restricting the entire analysis to whichever arm each reader follows best.

## 4. Q3–Q5 need outcome definitions before 'validity' or 'ensemble gain' has meaning

Successful intervention labels identify a directed effect on a designated answer. They do not label all named concepts in a description as true, used or false. A reader may correctly report a source cue or an unrelated fact without that content being part of this causal contrast. An incorrect bridge answer can coexist with an accurate description. 'Unsupported by this experiment' and 'factually false' should remain separate annotation categories.

Off-path concepts, random slices and prompt-only outputs are useful comparators, but do not automatically supply matched negative ground truth for causal use. Random slices can retain real signal. A prompt-only reader can infer the bridge correctly. A failed intervention can still alter genuine bridge information. Therefore claims about ensemble precision/recall against demonstrated use are premature without a defined candidate universe, a finite scoring question and appropriate positive/negative labels.

For a first analysis, define a narrow benchmark: how well do prespecified reader scores discriminate interventions that reach the designated answer outcome, conditional on the intervention family and sample? Compare the ensemble with the best prespecified individual reader on held-out items or relation groups if parameters/thresholds are fitted. This establishes predictive utility for the assay. It is not truth recovery. Cohen's kappa is also descriptive and prevalence-sensitive; target imbalance, notably Japan, can make aggregate results misleading. Per-target and per-relation reporting is a good existing requirement, but many groups will be too small for precise estimates.

The Stage C state list names working arms, while its reading rule requires failed/random comparisons. Resolve this before capture: store and read a prespecified set of clean, successful, partial, unsuccessful and random conditions. Capture eligibility must not depend on the reader score. Otherwise the main diagnostic comparison will be missing or selected after seeing results.

Finally, Q5 can establish that information is decodable through a reader after removing one specified dense J projection. That is not evidence that the information is outside a functional workspace. The workspace hypothesis and this numerical projection are not interchangeable definitions.

## 5. Useful controls, but some gates and covariates are being asked to do too much

The actual-render clean gate, source-preserving random-target intervention, isotropic control, real-target reference, downstream reading, split disclosure and stop-after-smoke policy are all worthwhile. They address concrete historical failure modes.

However, a failed answer-direction positive control invalidates an interpretation of a bridge null; it does not erase a robust positive bridge intervention. The stop rule should distinguish those situations. A bridge direction could work in a band where a particular answer direction does not. The answer arm is also a mechanistic comparator: if readers and the model behave similarly under direct answer steering, that threatens a special bridge-replacement interpretation.

Output rank/D and prompt-only scores are useful measurements. Regressing out one scalar cannot establish independence from all output-facing information or all prompt inference. Post-intervention output is itself downstream of the intervention, so adjusting for it changes the question: it estimates incremental reader utility beyond that measured output, not the total relation between reader response and answer movement. State which question is being answered. Do not make a partial-correlation coefficient the verdict on faithfulness.

Editing all positions does not make stripping a trailing space immaterial. It changes the rendered prompt, tokenization and baseline computation. Reference-engine replication can legitimately use the reference render, but the resulting reader capture and target reference must use that same rendered input. Reusing 007 clean reads from another rendering requires demonstrated equivalence, not an assumption.

The inference that a multihop lever explains 008's brew atom null through band and position choice also changes task family simultaneously. It motivates a band/position hypothesis, not a diagnosis of the old null. Comparisons within the multihop bank can isolate band effects there; attribution of the brew contrast requires a same-family comparison.

## Minimum useful next sequence

1. Authorize the cheap, correctly scored Stage A replication and short-band tests, with clean-correct denominators and per-target counts. It answers whether a common upstream intervention exists for on-contract Oracle and NLA comparisons. Report the exact prompt rendering. The present four-item smoke cannot settle this.
2. On a small prespecified shared-item sample, establish one effective early band and compare clean / targeted edit / matched random edit / real-target reference. Read whole activations first with Oracle L40/L44 and NLA L42 from the same trajectories. Include outcome classes whether or not they flip. A J-independent class-mean arm is valuable once a broader reader ranking is attempted, but dense-piece expansion and every alternative handle need not precede this basic test.
3. Primary outcomes: the model's continuous margin change and strict answer outcome; each reader's within-item target-over-source change; source/target/both/neither naming; the same scores on natural-target references. Ask whether reader changes distinguish targeted effects from random interventions and whether they predict outcome beyond simple baselines. Inspect representative disagreements.
4. If the reference controls separate source from target but neither reader changes during effective interventions, distinguish cell localization from reader insensitivity before concluding reader failure. If the readers change equally during ineffective and effective edits, conclude intervention sensitivity without outcome specificity. If one reader predicts outcomes better on a matched sample, that is useful evidence about this assay. Escalate to causal cell transfer/rescue or relation-specific transfer only if the desired claim requires it.
