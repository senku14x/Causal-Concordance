# 012 Stage R audit: a shared signal, with the Stage F mask bug inherited

Independent Codex scientific audit, 2026-10-07. Repository, source clones and canonical experiment outputs were read-only. No GPU, project workflow, dependency changes or experiment reruns. Scope: completed Stage R broadcast results, their relationship to the prior Stage F2 correction, and the claimed need for a fresh hidden-bridge replication. Stage E/AR work is outside this report.

## Conclusion

Stage R establishes that, on these broadcast prompts and interventions, all tested readers' early-position shifts predict the answer outcome well, and the model's own early-position output statistic predicts it at least as well by point estimate. It does not provide evidence for an NLA-specific advantage over Oracle L44 or an association beyond the measured output baseline.

The Stage F2 position-mask bug was copied into Stage R. Repairing it analytically leaves Stage R's nonreplication verdict unchanged, but removes the apparently positive residual-association point estimates. Meanwhile the canonical Stage F summary still contains the incorrect 0.72 AUC / 0.54 partial headline. The priority is a canonical CPU correction and an updated scientific interpretation, not treating that headline as an unresolved positive finding requiring more GPU work.

## Same mask bug, and two coherent endpoint choices

`stageR_analysis.py` reuses Stage F's `keep()` pattern: discard the predecessor of the final token when that final token is ` is`, using an `is_read_minus_1` flag. `f2_model.jsonl` contains this flag. Both reader JSONL files omit it, so the model average drops the predecessor while the reader average keeps it.

There are **36** prompts ending in ` is` across all 192 items, **33** in the primary cohort and **23** among the 109 toward-target items. Thus the discrepancy is active in Stage R.

The written §16 calls its protocol identical to F2 but explicitly says to read every position before the read token, without restating F2's predecessor exclusion. Therefore there are two reasonable shared-mask analyses. Neither supports a positive NLA residual association.

## Direct reader differences

Using the all-early endpoint and paired 10,000-draw source-cluster bootstrap, seed 20261007:

- **NLA minus Oracle L44 AUC:** **-0.0004058442**, interval **[-0.0191390254, 0.0197368421]**.
- NLA minus Oracle L40 AUC: 0.0328733766, interval [0.0049016180, 0.0790234520].
- NLA minus model bridge-output AUC: -0.0158279221, interval [-0.0648481765, 0.0119057409].

Under the shared F2-exclusion endpoint, NLA and Oracle L44 have exactly the same AUC, with paired interval [-0.0177064410, 0.0197368421].

Thus NLA and Oracle L44 perform very similarly for this discrimination endpoint. The modest NLA advantage over Oracle L40 does not constitute an advantage over the Oracle as a reader family. The model baseline also leaves no demonstrated AUC advantage for NLA. These paired comparisons are post hoc; the uncertainty conditions on this source set, intervention and scoring rule. No universal equivalence claim follows.

The modest number of source clusters and shared prompt templates limit generalization. A nonsignificant partial correlation is not evidence of no additional reader information, but here neither the point estimates after correction nor the direct reader comparisons motivate a special NLA interpretation.

## What R adds, and what remains stale

R adds a second family where reader response and intervention outcome covary strongly. The source concept is explicit in short prompts, unlike multihop. This makes it useful evidence about the shared sensitivity of these instruments to edited concept-related states, not a test that isolates an unstated intermediate. At early positions the subject model's output distribution predicts the next prompt token, not the eventual answer, so its bridge-tail score remains an accessibility diagnostic rather than a mechanism or complete control for future answer information.

The ledger says broadcast is a weak test of the original F2 hint and proposes fresh hidden-bridge items. Changing family is a real limitation, but it is not the main obstacle now. The original F2 positive interpretation relied on mismatched position sets. The canonical `stageF_analysis.json` still reports NLA AUC **0.7202380952** and partial **0.5359641359** at audit time. Under its intended common exclusion, the independent Stage F audit found **0.5853174603** and **0.1742155802**, with the partial interval including zero. Under an all-early shared mask the partial likewise loses its positive interval.

Consequently, the sentence that F2's positive NLA hint remains unconfirmed is incomplete: the particular evidence for that hint has been undermined by a diagnosed analysis error. A fresh hidden-bridge study could pursue a reformulated question, but is no longer the cheapest next action needed to evaluate the existing claim.

The bank is also not wholly untouched: Stage A already evaluated its intervention behavior. R contains new reader measurements on a changed family, rather than pristine held-out confirmation. Finally, the §16 rule that NLA-specificity follows if NLA passes while other readers fail significance is invalid as a reader-difference test. A paired comparison is the appropriate direct test, as above.
