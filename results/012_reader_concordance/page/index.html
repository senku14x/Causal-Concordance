13. Deleting false text: invented context is padding, misquotes carry the content

Δ = FVE after deleting the same amount of random text minus FVE after deleting the false text, in FVE points. Above 0: the false text carried more signal than average text. Grey band: within ±2 points. Interval: 95% cluster bootstrap over items.

False text is 64% of an average explanation. Two kinds behave differently. Invented context (made-up headers, quiz names, framings; about a quarter of the text) costs no more to delete than random text. Misquotes (paraphrases of the prompt in altered wording, about half the text) cost far more, because they still carry the bridge and the answer. The pre-registered headline ("false claims carry extra signal") comes from the misquotes. On 007's test half alone: invented context 0.4 [−1.6, 2.7], misquotes 34.5.
