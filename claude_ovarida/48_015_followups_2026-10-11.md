## 2. Answer swap test

**Design** (`swap.py`).
- Eligible: Oracle readouts with at least one bullet opening with the true answer (judge B's span) and one opening with
  a wrong answer (the rule in §3). That is 150 of 522 readouts.
- Only the readout's own strings are moved, so no new wording enters. Five seeds per version.

| Reconstructor | O − ALLW (true → wrong) | ALLT − O (wrong → true) | O − SWAP (exchange) | ALLT − ALLW |
|---|---|---|---|---|
| Oracle AR | +5.5 [3.7, 7.6] | −4.1 [−5.4, −3.0] | +3.6 [2.5, 5.0] | +1.3 [−1.1, 3.9] |
| NLA AR | +2.2 [0.6, 3.8] | −1.6 [−2.9, −0.4] | +0.3 [−0.7, 1.3] | +0.6 [−1.6, 2.7] |

- **Oracle AR:**
  - Mean FVE: O −60.0, ALLW −65.5, ALLT −64.1, SWAP −63.6.
  - By state the pattern repeats: O − ALLW +6.4 / +4.4 / +5.8, ALLT − O −4.9 / −3.7 / −3.9, O − SWAP +3.8 / +3.1 /
    +4.2 (clean / J / random).
- **Pre-stated readings:**
  - "favours the true answer" needed both O − ALLW and ALLT − O above 0;
  - "identity does not matter" needed both within ±2.
  - Neither holds. Both directions of change cost points, and so does an exchange that keeps the same strings. The
    direct true-vs-wrong comparison (ALLT − ALLW) is unresolved.
- **Sanity check:** the NLA AR scores the whole text at once, and the exchange leaves it unchanged (+0.3, inside ±2), as
  a same-set swap should. The Oracle AR scores bullet by bullet and is moved by it.
- **What this does to report 47:**
  - Δ_AP > 0 (deleting the true answer costs more than cutting another opening) still stands. But the true answer is
    not preferred to a wrong one written into the same place.
  - The Oracle AR's answer effect looks like "keep each bullet as written" more than "match the activation's answer".
  - This is a hypothesis: the swap test is post hoc and descriptive.

## 3. Runner-up test

**Design** (`runnerup.py`).
- **Wrong opening:** a bullet's opening up to the first punctuation, after stripping leading markup. It must be Latin
  script, at most 4 words, not a placeholder, and not the true answer (normalised, with number words). That gives 556
  openings; 372 unique (string, item, state), because the same opening in both samples counts once.
- **Score:** Qwen's full-sequence log-prob of the string as the continuation, log-sum-exp over 3 spellings, at the read
  cell. Stage B's exact edits are applied for the J and random states. The rank is that of the first token.
- **Null:** the same string at another item's read cell in the same state (seeded derangement).

| Strings | State | n | own − null (nats) | log-prob own / null | median rank own / null | top-10 own / null |
|---|---|---|---|---|---|---|
| Oracle's wrong openings | clean | 107 | +5.7 [3.9, 7.6] | −7.9 / −13.6 | 7 / 219 | 0.59 / 0.14 |
| | J swap | 130 | +7.2 [5.5, 9.1] | −7.0 / −14.2 | 4.5 / 282.5 | 0.58 / 0.12 |
| | random swap | 135 | +6.8 [5.1, 8.7] | −7.8 / −14.6 | 7 / 246 | 0.55 / 0.12 |
| | all | 372 | +6.6 [5.0, 8.3] | −7.5 / −14.2 | 7 / 253.5 | 0.57 / 0.12 |
| Model's own answer (positive control) | all | 261 | +13.5 [12.4, 14.6] | −1.0 / −14.4 | 1 / 1655 | 0.97 / 0.09 |

- **Gate (pre-stated: the argmax at every read cell equals Stage B's greedy first token): failed, 6 of 261 cells.**
  - All six are near-ties between spelling variants (' euro' / ' Euro', ' North' / ' north', ' the' before ' west').
  - The model's answer still ranks 1–2 at each, with first-token log-prob −0.7 to −1.2.
  - Two of the six are clean cells, where no edit applies.
  - Attributed to the bf16 forward path (one full forward here vs Stage B's generate prefill), not to edit reproduction.
  - Excluding those cells: +6.7 [5.0, 8.4] (n 364).
- **20 random examples** (seed 20) are in `results/015_oracle_hallucination/qualitative/runnerup_examples.md`. For
  example:
  - acropolis J swap: the model says Tokyo, the Oracle writes "Japan": rank 14 at its own cell, 15,392 elsewhere;
  - samba random swap: the model says Amazon, the Oracle writes "Rio Grande": rank 2;
  - smallest-continent random swap: the model says Europe, the Oracle writes "Asia": rank 2, 34,882 elsewhere.
  - The exceptions are mostly letter and antonym items: firstletter "G" for "O" at rank 746; armistice "alive" for
    "peace" at rank 1,902.
- **Rung:** a supported observation about these readouts. It does not say the Oracle *reads* the runner-ups from the
  activation, rather than inferring plausible alternatives from the prompt. The prompt-only baseline for that is
  WorkspaceBench's, and it is not run here.

## 4. Caveats

- Post hoc, descriptive, one family, one layer, these samples.
- The wrong-opening rule drops non-Latin openings (364 bullets) and long ones, so CJK wrong answers are not tested.
- The swap test covers 150 of 522 readouts, those with both kinds of opening.
- The runner-up log-probs are Qwen's, under bf16 replay of Stage B's edits; the 6-cell gate failure is as described above.
